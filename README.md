# Data Entry Quality Checker Agent

## Project Overview
This project is an AI-powered assistant built with Langflow to analyze repository content and explain how the project supports data entry quality checking, spreadsheet validation, and administrative workflow improvement.

## Project Goal
The goal of this project is to create an AI assistant that can help review, summarize, and explain data-related workflows for data entry, virtual assistant, and administrative tasks.

## Tools Used
- Langflow
- GitHub
- Gemini API
- Composio API
- AI Agent Workflow

## Workflow
1. User provides a GitHub repository link.
2. Langflow reads the repository content.
3. The AI agent analyzes the repository information.
4. The agent generates a clear explanation or portfolio summary.
5. The output can be used for documentation, portfolio, or LinkedIn project description.

## Expected Result
The assistant helps users understand the project faster and produces structured explanations that are useful for portfolio building, documentation, and data entry quality improvement.

## Portfolio Value
This project demonstrates basic AI agent building skills, GitHub integration, API setup, prompt writing, and workflow testing using Langflow.
